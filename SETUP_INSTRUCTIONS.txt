========================================
VaultX OTP System - SETUP INSTRUCTIONS
========================================

To make the OTP registration and password reset work, you MUST do these steps:

STEP 1: Download PHP Mailer
============================
1. Go to: https://github.com/PHPMailer/PHPMailer
2. Click on the green "Code" button
3. Click "Download ZIP"
4. Extract the downloaded file

STEP 2: Copy PHP Mailer Files
==============================
The extracted folder should have a "src" folder with 3 files:
  - PHPMailer.php
  - Exception.php
  - SMTP.php

Copy these 3 files to:
  YOUR_PROJECT/vendor/PHPMailer/src/

After copying, your folder structure should look like:
  vendor/
  ├── PHPMailer/
      └── src/
          ├── PHPMailer.php
          ├── Exception.php
          └── SMTP.php

STEP 3: Configure Email Settings
==================================
Edit the file: config/email.php

You need to set these values (choose one provider):

OPTION A: Using Gmail
---------------------
define('SMTP_HOST', 'smtp.gmail.com');
define('SMTP_PORT', 587);
define('SMTP_USER', 'your-email@gmail.com');
define('SMTP_PASS', 'your-app-password');  // Generate at: https://myaccount.google.com/apppasswords
define('FROM_EMAIL', 'your-email@gmail.com');
define('FROM_NAME', 'VaultX');

OPTION B: Using Mailtrap (Free testing service)
-----------------------------------------------
Sign up at: https://mailtrap.io
define('SMTP_HOST', 'smtp.mailtrap.io');
define('SMTP_PORT', 465);
define('SMTP_USER', 'your-mailtrap-user');
define('SMTP_PASS', 'your-mailtrap-password');
define('FROM_EMAIL', 'your-email@example.com');
define('FROM_NAME', 'VaultX');

OPTION C: Using SendGrid
------------------------
Sign up at: https://sendgrid.com
define('SMTP_HOST', 'smtp.sendgrid.net');
define('SMTP_PORT', 587);
define('SMTP_USER', 'apikey');
define('SMTP_PASS', 'SG.your-api-key');
define('FROM_EMAIL', 'your-verified-sender@example.com');
define('FROM_NAME', 'VaultX');

STEP 4: Create Database Tables
================================
Run this SQL in your database:

CREATE TABLE IF NOT EXISTS otp_verification (
    id INT AUTO_INCREMENT PRIMARY KEY,
    email VARCHAR(255) NOT NULL,
    otp VARCHAR(6) NOT NULL,
    otp_type ENUM('registration', 'password_reset') DEFAULT 'registration',
    is_verified BOOLEAN DEFAULT FALSE,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    expires_at TIMESTAMP,
    INDEX idx_email (email),
    INDEX idx_otp_type (otp_type),
    INDEX idx_expires (expires_at)
);

ALTER TABLE users ADD COLUMN IF NOT EXISTS email VARCHAR(255) UNIQUE;

STEP 5: Test the Setup
=======================
Visit in your browser:
  http://your-server/vaultx/check_setup.php

This will show you:
  ✓ If PHP Mailer files are found
  ✓ If database is connected
  ✓ If tables exist
  ✓ If email config is set

You can also send a test email from there.

STEP 6: Try Registration
=========================
Go to: http://your-server/vaultx/public/register.php

You should now be able to:
  1. Fill in the registration form
  2. Click "Send OTP to Email"
  3. Receive an email with a 6-digit code
  4. Enter the code to complete registration

TROUBLESHOOTING
================

Issue: "An error occurred. Please try again."
Solution: 
  - Check check_setup.php for what's missing
  - Make sure PHP Mailer files are in vendor/PHPMailer/src/
  - Make sure email config is correct

Issue: Email not being sent
Solution:
  - Check if SMTP credentials are correct
  - Try the test email feature in check_setup.php
  - Check your email provider's security settings
  - Gmail may require "App Passwords" instead of regular password

Issue: Database error
Solution:
  - Make sure the otp_verification table was created
  - Make sure the email column was added to users table
  - Run the SQL from STEP 4 again

Issue: PHP Mailer files not found
Solution:
  - Download from https://github.com/PHPMailer/PHPMailer
  - Extract and copy src/ folder to vendor/PHPMailer/src/
  - Make sure all 3 files are there (PHPMailer.php, Exception.php, SMTP.php)
